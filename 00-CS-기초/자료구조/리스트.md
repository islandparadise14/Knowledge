
# Kotlin Array / List / TypedArray 정리

---

## 큰 그림

```
Kotlin 컬렉션
├── Array<T>            제네릭 배열 (참조 타입)
│   ├── Array<Int>      내부적으로 Integer[] (박싱됨, 느림)
│   ├── Array<String>   String[]
│   └── Array<MyObj>    커스텀 객체
│
├── TypedArray          원시 타입 전용 (빠름)
│   ├── IntArray        int[]
│   ├── LongArray       long[]
│   ├── BooleanArray    boolean[]
│   ├── DoubleArray     double[]
│   └── CharArray       char[]
│
└── List<T>             인터페이스 (크기 가변)
    ├── listOf()        불변
    └── mutableListOf() 가변
```

---

## 핵심 차이

```kotlin
// TypedArray → 크기 고정, 원시타입, 빠름
val a = IntArray(5)          // [0,0,0,0,0]
a[0] = 1                     // 수정 가능
a.add(6)                     // ❌ 크기 고정

// Array<T> → 크기 고정, 제네릭, String/객체용
val b = arrayOf("a", "b")
b.add("c")                   // ❌ 크기 고정

// MutableList → 크기 가변
val c = mutableListOf<Int>()
c.add(1)                     // ✅ 가능
```

---

## 왜 TypedArray가 따로 있냐

```kotlin
// Array<Int> → Integer (객체) 로 저장 = 박싱/언박싱 비용
val boxed: Array<Int> = arrayOf(1, 2, 3)      // Integer[]

// IntArray → int (원시타입) 로 저장 = 빠름
val primitive: IntArray = intArrayOf(1, 2, 3) // int[]
```

> 숫자는 항상 TypedArray 쓰는 게 맞다

---

## 변환 관계

```kotlin
// TypedArray → List
intArrayOf(1,2,3).toList()
intArrayOf(1,2,3).toMutableList()

// List → TypedArray
mutableListOf(1,2,3).toIntArray()
mutableListOf(1L,2L).toLongArray()

// List<String> → Array<String>
mutableListOf("a","b").toTypedArray()    // String은 TypedArray 없음

// TypedArray → Array<T> (박싱 발생)
intArrayOf(1,2,3).toTypedArray()         // Array<Int> (Integer[])
```

---

## toTypedArray() vs toLongArray()

```kotlin
mutableListOf<Long>().toTypedArray()  // → Array<Long>  ← 박싱된 Long 객체
mutableListOf<Long>().toLongArray()   // → LongArray    ← 원시타입 long[]
```

> `toTypedArray()`는 항상 `Array<T>` (박싱 버전)을 만든다 숫자에 `toTypedArray()` 쓰면 느려짐

---

## 코테에서 판단 기준

```
숫자, 크기 앎      → IntArray(n) { } / LongArray(n) { }
숫자, 크기 모름    → mutableListOf<Int>()  → toIntArray()
                    mutableListOf<Long>() → toLongArray()

문자열 반환        → mutableListOf<String>() → toTypedArray()
객체 반환          → mutableListOf<MyClass>() → toTypedArray()
```

> `toTypedArray()`는 String이나 커스텀 객체 반환할 때만 쓴다

## 생성 방법 한눈에 보기

```kotlin
// 크기 알 때 (람다로 초기값 계산)
IntArray(n) { it * 2 }           // [0, 2, 4, ...]
LongArray(n) { x.toLong() * (it + 1) }

// 크기 모를 때
val list = mutableListOf<Int>()
list.add(1)
list.toIntArray()

// 고정값으로 선언
intArrayOf(1, 2, 3)
longArrayOf(1L, 2L, 3L)
arrayOf("a", "b", "c")
```
