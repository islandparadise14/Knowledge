# Kotlin 숫자 ↔ 문자열 변환 총정리

---

## 기본 변환

```kotlin
// String → 숫자
"123".toInt()
"123".toLong()
"3.14".toDouble()
"123".toFloat()

// 실패해도 안 터지게 (null 반환)
"abc".toIntOrNull()        // null
"123".toIntOrNull()        // 123

// 숫자 → String
123.toString()
3.14.toString()
```

---

## 진법 변환

```kotlin
// 10진수 → n진법 문자열
Integer.toBinaryString(10)      // "1010"  (2진법)
Integer.toOctalString(10)       // "12"    (8진법)
Integer.toHexString(255)        // "ff"    (16진법)
10.toString(2)                  // "1010"  (2진법) ← Kotlin 방식
10.toString(16)                 // "a"     (16진법)
255.toString(16)                // "ff"

// n진법 문자열 → 10진수
"1010".toInt(2)                 // 10   (2진법 → 10진법)
"ff".toInt(16)                  // 255  (16진법 → 10진법)
"12".toInt(8)                   // 10   (8진법 → 10진법)
```

## 문자(Char) ↔ 숫자

```kotlin
// Char → Int (ASCII)
'A'.code                        // 65
'a'.code                        // 97
'0'.code                        // 48

// Int → Char (ASCII)
65.toChar()                     // 'A'
97.toChar()                     // 'a'

// 알파벳 인덱스 (a=0, b=1, ...)
'a' - 'a'                       // 0
'z' - 'a'                       // 25
'C' - 'A'                       // 2

// 숫자 문자 → Int (toInt() 쓰지 말라고 할 때)
'7' - '0'                       // 7  ← ASCII 차이로 계산
'7'.digitToInt()                // 7  ← Kotlin 내장

// Int → 숫자 문자
7 + '0'.code                    // 55 (ASCII)
(7 + '0'.code).toChar()         // '7'
```

## 문자열 ↔ 문자 배열

```kotlin
val s = "hello"

// String → CharArray
s.toCharArray()                  // ['h','e','l','l','o']

// String → List<Char>
s.toList()                       // ['h','e','l','l','o']

// CharArray → String
charArrayOf('h','i').joinToString("")       // "hi"
charArrayOf('h','i').concatToString()       // "hi"  ← 더 간결
String(charArrayOf('h','i'))                // "hi"

// List<Char> → String
listOf('h','i').joinToString("")            // "hi"
```

## 숫자 각 자릿수 다루기

```kotlin
val n = 12345

// 각 자릿수 리스트로
n.toString().map { it.digitToInt() }        // [1, 2, 3, 4, 5]
n.toString().map { it - '0' }               // [1, 2, 3, 4, 5]

// 자릿수 합
n.toString().sumOf { it.digitToInt() }      // 15

// 자릿수 개수
n.toString().length                         // 5

// 각 자릿수 역순
n.toString().reversed()                     // "54321"
n.toString().reversed().toInt()             // 54321
```

## toInt() 못 쓸 때 대안

```kotlin
// 방법 1: 자릿수 직접 계산
fun strToInt(s: String): Int {
    var result = 0
    for (c in s) {
        result = result * 10 + (c - '0')
    }
    return result
}

// 방법 2: digitToInt() 활용
"123".fold(0) { acc, c -> acc * 10 + c.digitToInt() }  // 123

// 방법 3: reduce
"123".map { it.digitToInt() }.reduce { acc, d -> acc * 10 + d }  // 123
```

## 자주 나오는 변환 패턴

```kotlin
// 숫자 배열 → 하나의 숫자
intArrayOf(1,2,3).joinToString("").toInt()   // 123

// 숫자를 뒤집기
12345.toString().reversed().toInt()           // 54321

// 특정 진법으로 변환 후 자릿수 합
255.toString(2)                               // "11111111"
    .sumOf { it.digitToInt() }               // 8

// 문자열에서 숫자만 추출
"a1b2c3".filter { it.isDigit() }             // "123"
"a1b2c3".filter { it.isDigit() }.toInt()     // 123

// 대소문자
"Hello".uppercase()                           // "HELLO"
"Hello".lowercase()                           // "hello"
'A'.lowercaseChar()                           // 'a'
'a'.uppercaseChar()                           // 'A'
```

## 판단 함수

```kotlin
val c = '5'
c.isDigit()       // true  (숫자 문자인지)
c.isLetter()      // false (알파벳인지)
c.isLetterOrDigit()
c.isUpperCase()
c.isLowerCase()
c.isWhitespace()
```
