# BFS / DFS 수도코드 정리

---

## BFS (너비 우선 탐색)

> **주어진 것:** 그래프 or 격자, 시작점 **구하는 것:** 시작점에서 각 노드까지 **최단거리**

```kotlin
BFS(graph, start) {

    // 필수 자료구조
    visited = BooleanArray(n)         // 방문 여부
    dist = IntArray(n) { -1 }         // 거리 (정답)
    queue = ArrayDeque()              // 탐색 순서 줄세우기

    // 시작점 세팅
    queue.add(start)
    visited[start] = true
    dist[start] = 0

    // 탐색
    while (queue 안 비었으면) {
        cur = queue.removeFirst()

        for (next in graph[cur]) {
            if (!visited[next]) {
                visited[next] = true
                dist[next] = dist[cur] + 1
                queue.add(next)
            }
        }
    }

    return dist
}
```

BFS 로 완전 탐색 할때는 

```kotlin
for { -> 인접한 노드를 다 탐색하는 행위를 노드마다 실행한다. -> (완전탐색)
	while () -> 너비를 우선으로 하지만 인접한 노드를 다 탐색한다. -> BFS
}
```

** visit 는 queue 에 add 하는 타이밍에 할것 **
```kotlin
visited[next] = true
queue.add(next)
```

## DFS (깊이 우선 탐색)

> **주어진 것:** 격자(board), 시작점 (x, y) **구하는 것:** 연결된 구역 **개수**

```kotlin
solution(board) {

    // 필수 자료구조
    visited = Array(n) { BooleanArray(m) }  // 방문 여부
    dx = [0, 0, 1, -1]                      // 4방향 변화량 (상하좌우)
    dy = [1, -1, 0, 0]
    count = 0                               // 정답

    // 전체 순회하면서 새 구역 발견시 dfs 호출
    for (x in 0..n) {
        for (y in 0..m) {
            if (!visited[x][y] && board[x][y] == '1') {
                dfs(x, y)
                count++
            }
        }
    }

    return count
}

dfs(x, y) {
    visited[x][y] = true

    for (i in 0..3) {
        nx = x + dx[i]
        ny = y + dy[i]

        if (범위 벗어남) continue        // nx < 0 || ny < 0 || nx >= n || ny >= m
        if (visited || board == '0') continue

        dfs(nx, ny)                      // 재귀로 파고들기
    }
}
```

for 문 없이 dfs 만 재귀하면 경우의 수
```kotlin
dfs(list, target, 0, 0)

dfs(list, target, depth, sum) {
	if (depth == list.size) {
		return if (sum == target) 1 else 0
	}

	return dfs(경우 1) + dfs(경우 2) + dfs(경우 3) + dfs(경우 4)
}
```

## 암기 포인트

||BFS|DFS|
|---|---|---|
|핵심 자료구조|Queue + dist 배열|visited + 이중 for 외부 호출|
|구하는 것|최단거리|연결된 구역 개수|
|자료구조|Queue (줄)|재귀 호출 스택|
|탐색 방식|가까운 것부터|한 방향 끝까지|

```
Q. 최단거리 / 최소횟수 물어봄?   → BFS

Q. 둘 다 될 것 같음?             → BFS 먼저 시도
```

## dx / dy 방향 배열

```
dx = [0,  0, +1, -1]   // x 변화량
dy = [+1, -1,  0,  0]  // y 변화량

i=0 → (x,   y+1) → 오른쪽
i=1 → (x,   y-1) → 왼쪽
i=2 → (x+1, y  ) → 아래
i=3 → (x-1, y  ) → 위
```

> x = 행 (아래로 증가), y = 열 (오른쪽으로 증가) `for (i in 0..3)` 하나로 4방향 전부 처리
