---

## import 총정리 (헷갈리면 여기서 확인)

```kotlin
import java.util.PriorityQueue    // 우선순위 큐
import java.util.LinkedList       // LinkedList 기반 Queue (가끔)
import java.util.Stack            // Stack (거의 안 씀, ArrayDeque 쓸 것)

// ArrayDeque, MutableList, MutableMap, MutableSet → import 필요 없음 (Kotlin 기본)
// Int, Long, String, Boolean → import 필요 없음
```

> **꿀팁:** 프로그래머스는 `PriorityQueue` 빼고 거의 import 안 써도 됨


## Queue (BFS 필수)

```kotlin
// import 필요 없음 (ArrayDeque는 Kotlin 기본)

val queue = ArrayDeque<Int>()
queue.add(1)              // 뒤에 추가
queue.removeFirst()       // 앞에서 꺼냄
queue.isEmpty()
queue.isNotEmpty()

// Pair로 쓸 때 (x, y 좌표)
val queue = ArrayDeque<Pair<Int, Int>>()
queue.add(Pair(0, 0))     // 또는 queue.add(0 to 0)
val (x, y) = queue.removeFirst()
```

## Stack (DFS 반복문 버전)

```kotlin
// import 필요 없음 (ArrayDeque로 대체)

val stack = ArrayDeque<Int>()

stack.removeLast()        // pop

```

## 우선순위 큐 (최소힙)

```kotlin
import java.util.PriorityQueue    // ← 얘만 import 필요!

val pq = PriorityQueue<Int>()               // 오름차순 (최솟값 먼저)
val pq = PriorityQueue<Int>(reverseOrder()) // 내림차순 (최댓값 먼저)
pq.add(3)
pq.poll()     // 꺼내기
pq.peek()     // 안 꺼내고 보기
pq.isEmpty()
```

## 컬렉션 함수

```kotlin
// import 필요 없음

val list = listOf(3, 1, 4, 1, 5, 9, 2, 6)

// 정렬
list.sorted()
list.sortedDescending()
list.sortedBy { it.length }
list.sortedByDescending { it }

val mList = mutableListOf(3, 1, 2)
mList.sort()                         // 원본 정렬 (in-place)

// 필터 / 변환
list.filter { it > 3 }
list.map { it * 2 }
list.count { it > 3 }

// 집계
list.sum()
list.maxOrNull()
list.minOrNull()

// 그룹핑
list.groupBy { it % 2 }              // { 0: [짝수들], 1: [홀수들] }

// 첫번째 / 마지막
list.first()
list.last()
list.firstOrNull { it > 10 }

// 포함 여부
list.contains(5)   // 또는 5 in list

// 합치기
list.joinToString(" ")
list.joinToString(", ")
```

## 암기 우선순위

```
1순위 (BFS/DFS 필수)
  - ArrayDeque 선언 / add / removeFirst     → import 없음
  - IntArray, BooleanArray, Array(n){ }     → import 없음
  - Pair 선언, to 문법, 구조분해             → import 없음

2순위 (구현 필수)
  - split / map / toInt                     → import 없음
  - filter / map / count / sum              → import 없음
  - sorted / sortedBy                       → import 없음

3순위 (가끔)
  - PriorityQueue                           → import java.util.PriorityQueue
  - StringBuilder                           → import 없음
  - groupBy                                 → import 없음
```
